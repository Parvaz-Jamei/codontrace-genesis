# CodonTrace / GENESIS Feature Wiring Matrix

Research-alpha status matrix for public/runtime feature surfaces. Public API presence is not a claim. Claims require runtime effect, evidence artifact, replay/digest support, and conservative ClaimGate eligibility.

| Feature | Public API | Runtime effect | Default status | Pilot status | Evidence artifact | Claim eligible | ClaimGate reason | Known limitation |
|---|---|---|---|---|---|---|---|---|
| Evolution pilot | `GenesisRuntimeProfile.evolution_pilot_world`, reproduction records | resources, COPY_SELF, mutation, capacity/selection pressure | wired_default_off | runtime_effective_in_pilot | evolution CSV/JSON, birth/gate/selection records | claim_eligible_limited | births/resource/selection evidence required | not a full Avida replacement |
| QD selection | `EvolutionConfig.qd_mode`, `QDArchive`, `qd_selection_audit` | novelty-weighted selection can change survivor/parent set | wired_default_off | runtime_effective_in_pilot | `qd_selection_pilot.json` | claim_eligible_limited when `qd_changed_selection=True` | `selection_applied` | archive-only never proves QD pressure |
| Toolchain | `CodonTable.genesis_toolchain_v0`, `ToolChainRecord` | successful collection + state-changing tool actions + reward | wired_default_off | runtime_effective_in_pilot, `chain_success=True` | `toolchain_pilot_summary.json`, `toolchain_pilot_records.jsonl` | claim_eligible_limited | `toolchain_success_path_observed` | task meaning remains scenario-defined |
| Capsule usefulness | capsule adoption/utility records | causal/behavior digest change + paired utility micro-evaluation | wired_default_off | `positive_utility_observed` | `capsule_utility_summary.json`, `capsule_utility_records.jsonl` | claim_eligible_limited | positive utility + behavior digest change | controlled utility is not universal capsule learning |
| Memory delayed reward | `MemoryUseEvidence`, `DelayedRewardTrace` | signal/write/read-or-action/reward chain | wired_default_off | runtime_effective_in_pilot | `memory_delayed_reward.json` | claim_eligible_limited | complete delayed reward chain | proxy memory events alone are not strong evidence |
| Social interaction | `SocialInteractionEvent`, partner records | real non-capsule agent-to-agent resource/fitness/world delta | wired_default_on filter, pilot off by default | runtime_effective_in_pilot with `non_capsule_social_events>=1` | `social_partner_summary.json`, `social_partner_events.jsonl` | claim_eligible_limited for interaction only | non-capsule delta event observed | social intelligence remains denied |
| Social intelligence | heldout/partner protocol fields | familiar/unfamiliar export only unless stronger metrics are added | claim_denied_pending_evidence | denied | social partner manifest | no | heldout partner protocol not sufficient by itself | needs comparative familiar/unfamiliar performance metrics |
| Resource respawn | `RuntimeResourcePolicy`, resource events | deterministic resource regeneration under official RNG | wired_default_off | runtime_effective when enabled | resource policy records | claim_eligible_limited | respawn events and digest present | disabled/default worlds cannot claim regeneration |
| ADF | ADF registry/execution records | primitive status/energy/ledger aggregation | wired_default_off | fixture-tested | trace world_delta primitive commit fields | claim_eligible_limited only with runtime effect | primitive commits recorded | usefulness needs paired task evidence |
| Benchmark v2 | behavior specs, scenario suite | scenarios either build runtime worlds/toggles or deny evidence | wired_default_off | guarded | benchmark manifests/digests | conservative | metadata-only blocked | not a full campaign by itself |
| Generalization/Heldout | snapshots/specs/proxy records | export primitives; engine proxy provisional | evidence_scaffold_only | provisional | generalization records/snapshots | no for proxy | proxy not claim eligible | runner-level heldout required |
| Substrate Bridge | substrate runtime bridge | audit/extension hook unless integrated action changes state | extension_only | no official claim pilot | bridge status records | no | audit_only_not_integrated | not integrated runtime semantics by default |
| Birth/Reproduction | `reproduce`, population reproduction records | gated child creation, placement, mutation, cost audit | wired_default_off | runtime_effective_in_pilot | birth/gate/lineage/admission records | claim_eligible_limited | births + gates + selection required | zero births may still be useful failure evidence |
| Fitness/Selection | raw fitness + `SelectionFitnessScore` | summaries separate raw, selection, viable scores | wired_default_on | all pilots | fitness breakdown + selection records | yes for selection-specific reports | selection score, not raw survival alone | raw survival is descriptive |
