# خلاصهٔ پورت میزبان–انگل دیجیتال CodonTrace (۲۰۲۶-۰۹-۲۴)

این بسته یک **DomainProfile اختیاری** به‌نام `host_parasite` است؛ **موتور جدا**
نیست و فیزیک عفونت را در `engine.py` پیاده نمی‌کند. این پروفایل فقط ادعاها را
برچسب‌گذاری می‌کند و پروتکل‌های اختیاری محیط/کمپین را فراهم می‌سازد.

## قفل دامنه

برای این پورت، نقش‌های دیجیتال **میزبان** و **انگل** با قیاس میکروب–ویروس
کافی هستند. برای باکتری، آرکی یا سلول‌های آزمایشگاهی `DomainProfile` جداگانه
اضافه نمی‌شود. سلول‌های Genesis همان بستر ALife دامنه‌خنثی می‌مانند و
`host_parasite` فقط ادعاها و پروتکل‌های اختیاری محیط/کمپین را برچسب‌گذاری
می‌کند. ژنتیک CRISPR، عفونت درون موتور و بسته‌های گونه‌شناختی خارج از دامنه‌اند.
جزئیات بستهٔ افزودهٔ HE_HP در
[`docs/hard_experiment_hp/`](../../hard_experiment_hp/) آمده است.

## دامنهٔ ادعا

این پورت هیچ ادعای بالینی، اثربخشی واکسن/ضدویروس، درمان با فاژ، پیش‌بینی
اپیدمی، یا گواهی BSL ارائه نمی‌کند. شواهد و نتایج آن در محدودهٔ دیجیتال و برای
ممیزی ClaimGate باقی می‌مانند.
