# Publishing notes

Preferred release order:

1. Push a clean Git tag for the beta release.
2. Create a GitHub Release from that tag.
3. Archive the release through Zenodo if a DOI is desired.
4. Publish to PyPI using Trusted Publishing from GitHub Actions.

The package is beta research software. Public wording should describe deterministic primitives, replayable artifacts, ClaimGate-compatible evidence, and controlled experiments rather than unsupported claims of intelligence, artificial life, or open-ended discovery.
