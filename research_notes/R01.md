- **Core Principle:** In experimental coevolution, whether Red Queen dynamics occur is an empirical, testable hypothesis determined by reciprocal time-shift assays (contemporary vs past vs future cross-infection matrices). Negative frequency-dependent selection (aFDS) produces fluctuating oscillations without directional arms races. 
- **Methodological Rule:** An experiment must neither be dogmatically assumed to prove a hypothesis nor permanently hardcoded to false. An epistemically sound system must:
  1. Accept valid positive results when empirical data and assay controls satisfy criteria.
  2. Accept valid negative results when controls pass but empirical effects fail thresholds.
  3. Classify indeterminate or low-power runs as inconclusive.
  4. Classify corrupted or control-failing runs as invalid.
  5. Mark runs lacking registered protocols or still in progress as not evaluated.

## 2. Evidence Evaluator Schema

We define a 5-state categorical hypothesis evaluator:
- `supported`: The hypothesis is empirically supported by the experiment's metrics, statistical significance, and passing controls.
- `not_supported`: The run executed validly with intact controls, but the evidence rejects or fails to support the hypothesis (e.g. effect size below threshold, zero/negative slopes).
- `inconclusive`: Statistical power or duration is insufficient (e.g. sample size n < threshold, wide confidence intervals overlapping 0).
- `invalid`: The run encountered execution exceptions, broken invariants, violated positive/negative controls, or unmeasurable data.
- `not_evaluated`: The run is in progress, queued, or exploratory without an active registered hypothesis protocol.
