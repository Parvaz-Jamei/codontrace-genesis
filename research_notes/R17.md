# Research Note: Issue R17 - Process Cooperative Pause vs Worker Orphan Execution

- **Date**: 2026-10-08
- **Issue**: R17 (Process pause only stops parent while workers keep running; implement cooperative pause)
- **Component**: `codontrace.console.runs`, `rq_mechanism_v2_phase5`, `rq_full_engine_parallel`
- **Standard Reference**:
  - Operating Systems: Cooperative multitasking and inter-process synchronization markers (POSIX Advisory Locks & Marker Semantics).
  - Python `concurrent.futures.ProcessPoolExecutor` inter-process lifecycle management.
- **Model Assumptions**:
  - Pausing a batch simulation must pause both the orchestrator and all active workers across platforms (Windows, Linux, macOS) without pipe deadlocks or CPU spinning.
  - Aborting a simulation uses the `STOP` marker file.
  - Pausing a simulation uses a dedicated `PAUSE` marker file.
  - Workers must cooperatively check for `PAUSE` at generational boundaries and yield CPU via short sleep intervals (`time.sleep(0.2)`).
  - Resuming unlinks the `PAUSE` marker, allowing workers to continue uninterrupted.
- **Prior Art / Nearest Flaw**:
  - `send_signal_to_run` on Windows wrote `(entry / "STOP")`, triggering permanent engine abort rather than pause.
  - On POSIX, `send_signal_to_run` sent `SIGSTOP` only to the parent process; worker processes inside `ProcessPoolExecutor` continued executing at 100% CPU.
- **Proposed Difference**:
  - Implement cooperative pause: `send_signal_to_run(run_id, "PAUSE")` (and "STOP" for pause action) creates `entry / "PAUSE"` and `entry / "output" / "PAUSE"`.
  - Resume removes `PAUSE`.
  - Evolution loops (`run_phase5_history`, `monitor()`, `run_controlled_benchmark`) check for `PAUSE` on each generation and loop with `time.sleep(0.2)` while paused.
- **Testable Prediction**:
  - When paused, workers cease advancing generations and wait without burning CPU.
  - When resumed, workers seamlessly proceed to the next generation without losing state.
- **Decision**:
  - Implement cooperative file-based pause in console lifecycle and engine loops.
