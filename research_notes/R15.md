# Research Note: Issue R15 - Release ZIP Builder Traversal of Local Artifacts

- **Date**: 2026-10-08
- **Issue**: R15 (Release ZIP builder `tools/build_clean_release_zip.py` traversing output and node_modules/.git)
- **Component**: `tools/build_clean_release_zip.py`
- **Standard Reference**:
  - Python Packaging Authority (PyPA) source distribution specifications.
  - POSIX directory tree pruning via `os.walk` in-place modification of `dirnames`.
- **Model Assumptions**:
  - A clean release distribution package must contain only reproducible source, configuration, tests, and documentation.
  - Development artifacts (`.git`, `node_modules`, `output`, `simulation_runs`, `dist`, `build`, `.venv`, cache dirs) must be completely pruned before traversal.
  - The destination archive (`outp`) must be excluded to prevent recursion if created within the source tree.
- **Prior Art / Nearest Flaw**:
  - `build` used `base.rglob("*")` which eagerly traversed millions of files inside `.git`, `node_modules`, `output`, etc., and only checked an incomplete tuple `BAD` for substring matches.
- **Proposed Difference**:
  - Switch to `os.walk(base)` and prune `dirnames[:]` in-place using an explicit set `EXCLUDE_DIRS = {".git", "node_modules", "output", "simulation_runs", "dist", "build", ".venv", "venv", "__pycache__", ".pytest_cache", ".ruff_cache", ".mypy_cache", ".hypothesis", ".ipynb_checkpoints", ".phase3_"}`.
  - Exclude files matching `BAD_SUFFIX` or hidden/temporary patterns.
  - Ensure `p.resolve() != outp.resolve()`.
- **Testable Prediction**:
  - Building release zip finishes cleanly in under 5 seconds without containing any files from `.git`, `node_modules`, or `output`.
  - `tools/audit_release_zip.py` confirms `passed = true`.
- **Decision**:
  - Refactor `tools/build_clean_release_zip.py` with in-place pruning and explicit exclusions.
