# Technical and graphical sources — 2026-10-11

- [React lazy](https://react.dev/reference/react/lazy): defer the new Atlas module until its menu entry is opened.
- [React Suspense](https://react.dev/reference/react/Suspense): loading boundary for the optional view.
- [W3C SVG 2](https://www.w3.org/TR/SVG2/): vector scene and portable frame exports. This implementation uses isometric SVG, not a WebGL 3D physics scene.
- [WCAG 2.2: Use of Color](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html): shapes, text and inspector accompany color; no full-conformance certification claim.
- [Observable Plot color scales](https://observablehq.com/plot/features/scales): prior practice for categorical vs continuous color semantics. Genome color is categorical, not an energy magnitude scale.
- [React Three Fiber scaling performance](https://r3f.docs.pmnd.rs/advanced/scaling-performance): researched alternative for future large instanced WebGL scenes; not a dependency or implemented renderer here.
- [Three.js InstancedMesh](https://threejs.org/docs/pages/InstancedMesh.html) and [cleanup](https://threejs.org/manual/pages/cleanup.html): future GPU renderer would need instancing and explicit resource disposal.
- [deck.gl animations/transitions](https://deck.gl/docs/developer-guide/animations-and-transitions): comparative temporal-visualization design; no interpolation of scientific generations is implemented.

Visual decisions: dark observatory palette, isometric time sheets, precise sample scrubber, shape-coded lifecycle events, explicit recording bounds and separate numerical inspector. The user's requested 3D-print-slice metaphor is a presentation of time, not a claim of real 3D biological space.
