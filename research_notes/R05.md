# Research Note: Issue R05 - ZIP Export Symlink Traversal

- **Date**: 2026-10-08
- **Issue**: R05 (ZIP export traversal via symlinks in `console/runs.py::generate_run_zip_file`)
- **Component**: `codontrace.console.runs`
- **Standard Reference**:
  - CWE-59: Improper Link Resolution Before File Access ('Link Following').
  - CWE-22: Improper Limitation of a Pathname to a Restricted Directory ('Path Traversal').
  - Python pathlib security guidelines (PEP 428: strict containment checks via `Path.resolve()` and `Path.is_relative_to()`).
- **Model Assumptions**:
  - Run directories must be hermetic boundaries. Files exported into the ZIP must reside strictly within `entry.resolve()`.
  - Any symlink, hard link, or junction whose target resolves outside the run boundary must be discarded.
  - Omitted files must be logged in `export_manifest.json` under `omittedFiles` with a clear security audit reason.
- **Prior Art / Nearest Flaw**:
  - `generate_run_zip_file` iterated over `entry.rglob("*")` checking only `file_path.is_file()` and `file_path.relative_to(entry)`. When `file_path` was a symlink to an external file, `open()` followed the symlink outside the boundary, packaging host secrets or sentinel files into the archive.
- **Proposed Difference**:
  - Resolve canonical paths for all files with `target = file_path.resolve(strict=True)`.
  - For symlinks and regular files alike, verify `target.is_relative_to(entry_root)`. If false or if resolution errors occur, add to `omitted_files` and skip `zf.write()`.
- **Testable Prediction**:
  - A symlink pointing to an external file outside the run directory will not be written to the ZIP archive and will be listed in `omittedFiles`.
- **Decision**:
  - Implement strict canonical boundary containment enforcement in `generate_run_zip_file`.
