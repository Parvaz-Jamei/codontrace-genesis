# خلاصهٔ اجماع — پورت میزبان–انگل CodonTrace (۲۰۲۶-۰۹-۲۴)

این بسته یک **DomainProfile اختیاری** به‌نام `host_parasite` است؛ **موتور جدا**
نیست و فیزیک عفونت را پیاده نمی‌کند.

## اجماع MVP (۵ نکته)

1. ثبت پروفایل با شکستِ بسته‌شونده روی ادعاهای بالینی/واکسن/فاژتراپی/اپیدمی/BSL.
2. آداپتر نازک شبیه biomedical؛ بدون دست‌زدن به پین‌های BAIC و اعداد HE01.
3. موتور دامنه-خنثی می‌ماند؛ عفونت داخل `engine.py` نمی‌آید.
4. برچسب‌های ریسک/COU فقط اعلامی (FDA 2023 / V&V40)، نه مجوز بالینی.
5. کنترل‌های بعدی: null محتوا (HE02) + null ساختار + آزمون مداخله (Cornish).

## نوآوری‌های کارشناس C (برای v2)

- جعل‌پذیری دوقلوی دیجیتال زیر مداخله (Cornish et al. / arXiv:2301.07210).
- نردبان شواهد متناسب با ریسک ادعا (الگوی biomedical / V&V40).
- دو null: محتوا و ساختار؛ Price≠علّیت (Okasha & Otsuka 2020).
