# Design workshop — Wave 4 (mode completeness + cross-factorials)

**Context:** Wave 3 (Phases 10–13) sits on open PR tip `ee253fa`
(`feat/host-parasite-wave3-genome`). `MODE_AUDIT_WAVE4.md` found thin spots:
mixed-mode ClaimGate digests, `hgt_analogue_noise_transfer` missing from the
declared intervention menu, no genome×VT×spatial×continuum factorial, no
Gandon-style virulence/resistance *quality* diagnostics, and only a worksheet
for Okasha Price≠causality caution.

**Innovation bar:** ClaimGate-auditable protocols that deepen *under-used*
modes or honest cross-factorials genomes now enable. Refuse taxonomy theater,
infection-in-engine, and already-shipped duplicates.

**Roles**

- **A — Digital evolution / ALife** (Zaman; freeze≠replay≠reciprocal; mode digests)
- **B — Microbial / eco-evo** (Gandon resistance quality; VT/spatial continuum)
- **C — ClaimGate / V&V** (dual-null, prereg, blocked claims, Price≠causality)

## Round 1 — Force disagreement on what Wave 4 is *for*

**A:** Wave 4 must be **mode-completeness hardening first**. Reviewers will ask
“did you forget the modes you brainstormed?” If mixed still lacks a campaign
digest, and noise-transfer is off the menu, the Wave-3 HGT story looks half-
finished. Cross-factorials are nice but secondary to proving every kept mode
is exercised.

**B:** Disagrees on priority. Mode table hygiene is necessary but not
innovative. The unique earn-in is **genome × continuum × VT × spatial** —
Wave 2 and Wave 3 never crossed. Without that factorial, genomes and
Symbulation-style knobs remain siloed. Also: Gandon qualitative vs quantitative
resistance is the honest S7 surface and should not slip another wave.

**C:** Approves both only if:

1. No new DomainProfile; no `engine.py` touch; BAIC pins byte-identical.
2. Every new attach is prereg-bound and cannot raise the public ladder.
3. `virulence_optimized_for_humans`, `major_transition_proved`,
   `red_queen_proved`, phage therapy / clinical / CRISPR identity stay blocked.
4. Refuses “mode table as Phase” if it is only README prose — tests + digests
   required.

**Disagreement:** A wants Phase 14 = audit hardening only (small). B wants to
skip straight to genome×continuum. C forces a **thin but real** Phase 14
(menu + transmission-mode contrast digests + attach + mode-registry tests)
before Phases 15–16 innovation.

**Round-1 lock:** Phase 14 = mode-completeness hardening (not docs-only);
Phases 15–16 = innovation earn-ins; Phase 17 optional if 14–16 solid.

## Round 2 — Innovation pressure (keep / refuse)

**A — mode completeness protocol (Phase 14 refined):**

1. Register `hgt_analogue_noise_transfer` on `DECLARED_INTERVENTION_KINDS`.
2. `run_transmission_mode_contrast` campaign: horizontal / vertical / mixed
   produce pairwise-distinct digests; mixed must record both a successful
   horizontal inject and a vertical transmit event in the same run.
3. Soft-complete README **MODE table** pointing at code + tests.
4. Registry + tests that iterate brainstormed keep-modes and assert
   digest-backed exercise (or explicit refuse).

**B — genome × factorial + virulence quality:**

1. **Phase 15:** For each cell of VT × spatial × interaction_value, emit host
   and parasite `SemanticGenome.digest()` plus continuum scores. Distinct cell
   digests required for `candidate_evidence`. Mutualism never equals success.
2. **Phase 16:** Two labeled resistance *quality* proxies (digital only):
   - *qualitative*: seat / overlap gate (infect or not)
   - *quantitative*: graded steal_fraction or interaction_value drain
   Dual-null / contrast digests; ClaimGate attach refuses
   `virulence_optimized_for_humans`. Cite Gandon 2000 as literature comparator
   only (DOI already in CITATIONS/CHALLENGES).

**C — refuse / keep table:**

| Idea | Keep? | Why |
|---|---|---|
| Transmission-mode contrast digests + menu fix | **Keep — Ph14** | Audit gap; ClaimGate-auditable |
| README mode table + registry tests | **Keep (inside Ph14)** | Soft-complete; not taxonomy theater |
| Genome × VT × spatial × continuum factorial | **Keep — Ph15** | Cross Wave2×Wave3; genomes uniquely enable |
| Virulence/resistance quality proxies (S7) | **Keep — Ph16** | Labeled diagnostics; blocked claim stays blocked |
| Price≠causality refusal assay (S8) | **Defer — Ph17 optional** | Worksheet exists; earn if 14–16 green |
| Separate bacteria DomainProfiles | **Refuse** | No unique blocked-claim set |
| Infection in engine / wet HGT / CRISPR therapy | **Refuse** | Hard non-goals |
| Re-shipping Zaman three-arm or HGT four-arm | **Refuse** | Already shipped; deepen via cross/attach only |
| Proving major transition / Red Queen | **Refuse** | Forever False |

**Disagreement resolved:** B wanted virulence quality inside Phase 15; C+A
split it — Phase 15 stays factorial purity; Phase 16 owns S7 so blocked-claim
tests stay readable. A accepts Phase 17 only as optional earn-in after 14–16
green.

**New innovation accepted:** transmission-mode *contrast campaign* (not just
env unit tests) as a first-class ClaimGate surface; genome digests on the
continuum grid; qualitative vs quantitative resistance labels with human-
virulence claim still blocked.

## LOCKED Wave-4 phase plan

### Phase 14 — Mode-completeness hardening

- Fix `DECLARED_INTERVENTION_KINDS` (add noise-transfer).
- Transmission-mode contrast campaign + digests + prereg-bound attach.
- Mode registry exercised by tests; README / REQUIREMENTS mode table.
- Tests: `tests/test_host_parasite_phase14.py`; `PHASE14_REVIEW.md` (2 rounds).

### Phase 15 — Genome × (VT × spatial × continuum) factorial

- Cross Wave-2 continuum knobs with Wave-3 genome digests per cell.
- Pairwise-distinct cell digests for `candidate_evidence`; mutualism ≠ success;
  RQ / major-transition unproved.
- Tests + `PHASE15_REVIEW.md` (2 rounds).

### Phase 16 — Virulence / resistance quality proxies (S7)

- Qualitative vs quantitative digital proxies; dual-null / contrast digests.
- Attach refuses `virulence_optimized_for_humans`; never clinical / phage therapy.
- Tests + `PHASE16_REVIEW.md` (2 rounds).

### Phase 17 (optional earn-in) — Price≠causality refusal assay (S8)

- Digest-backed assay: Price-style summary present ⇒ causal / major-transition
  claims still refused; `major_transition_proved=False` always.
- Only if 14–16 solid and wall-clock allows.

### Hard non-goals (unchanged)

- New DomainProfiles; infection in `engine.py`; BAIC pin edits; `population/`
  junk; AI/agent/LLM meta in committed docs; wet HGT / conjugation / CRISPR
  identity / therapy; proved Red Queen / major transition / human virulence
  optimization; invented DOIs.
