# Zaman et al. 2014 — freeze/replay comparator

Zaman L, Meyer JR, Devangam S, Ofria C, Lenski RE, et al. (2014). Coevolution
drives the emergence of complex traits and promotes evolvability. *PLOS Biology*.
doi:[10.1371/journal.pbio.1002023](https://doi.org/10.1371/journal.pbio.1002023)

**Digital use in this port:** freeze/replay parasite task/payload lists across
host updates (Phase 4 campaign arm). This is an analogy for “parasite history
matters,” not a wet-lab replication and not a Red Queen proof.
