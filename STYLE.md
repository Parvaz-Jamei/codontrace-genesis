# Style

## Product naming

Use **CodonTrace Genesis** as the public product name. The installable
package and import remain `codontrace`.

- Docs, PRs, issues, and papers: **CodonTrace Genesis**
- `pip install` / `import`: `codontrace`
- Legacy module path `codontrace.genesis` is an implementation namespace

Do not publish an internal naming-order list in the README. That instruction
belongs here and in [`CONTRIBUTING.md`](CONTRIBUTING.md).

## Claims

Keep ClaimGate honest. Allowed observations are not intelligence,
collective intelligence, AGI, Tokyo Type 1 passed, or Avida-replacement
claims.
