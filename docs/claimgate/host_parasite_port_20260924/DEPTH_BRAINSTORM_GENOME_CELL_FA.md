# خلاصهٔ فارسی — طوفان فکری ژنوم × سلول / میکروب / باکتری

**CodonTrace Genesis** از قبل ژنوم سلول دارد. نتیجهٔ قفل‌شده:

- **یک** پروفایل ClaimGate به نام `host_parasite` کافی است.
- **سلول** = زیرلایهٔ دارای ژنوم (نه پروفایل جدا).
- **میکروب / باکتری** = برچسب COU و بستهٔ سنجش روی همان پروفایل (نه تئاتر آرایه‌شناسی).
- موج ۳ (در صورت اجرا): هضم ژنوم روی بازوهای Zaman + آنتروپی کدون با null دوگانه + پروتکل HGT-مانند و داخل‌سلولی/آزاد — **بدون** فیزیک عفونت در `engine.py` و بدون DomainProfile جدید.

ادعای مسدود (فاژتراپی، BSL، پاتوژن بالینی، هوش، Red Queen اثبات‌شده، گذار عمدهٔ اثبات‌شده، هویت CRISPR) مسدود می‌ماند.

جزئیات انگلیسی و DOIها: `DEPTH_BRAINSTORM_GENOME_CELL.md`.
