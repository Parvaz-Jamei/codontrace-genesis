# Non-goals and claim control

CodonTrace is a library-first foundation kernel aligned with selected early GENESIS Engine phases. It is not the full GENESIS Engine.

## Not implemented or not claimed

CodonTrace does not claim or implement:

- general-intelligence, subjective-awareness, or autonomous-general-intelligence product claims.
- life-like outcome validation.
- open-ended discovery validation or open-ended population evolution.
- Pearl-grade causality, causal-certainty claim, DoWhy/causal-learn style algorithms, Granger causality, or statistical causal discovery.
- publication-grade Causal Capsule / Stigmergy exchange.
- Publication-grade Discovery Witness archive, full Quality-Diversity / MAP-Elites search loop, automatic experiment execution, or publication-grade statistical engine.
- unrestricted dynamic code execution, eval/exec-based vocabulary growth, dashboards, report writers, notebooks, automatic config-file loading, GENESIS registry/plugin discovery through entry points, or file-writing pipelines in core.

## Current controlled implementations

- `CausalReplay` remains replay, not a learned causal graph.
- `CausalGraph` is implemented only as a local causal evidence scaffold. It stores auditable event evidence from `TraceEvent` and `EpisodicMemory`; it is not causal discovery or causal-certainty claim.
- `COPY_SELF` remains blocked in single-organism `GenesisOrganism` runs. Controlled reproduction exists only inside the explicit population lifecycle path with `ReproductionConfig`, AliveGate evidence, ATP checks, mutation metadata, and lineage records.
- `ATP_learning` consumption for bounded memory, consolidation scaffolds, dynamic vocabulary proposals, and local graph updates is operational, but it is not evidence of intelligence or life.
- ADF/Dynamic Vocabulary support in v0.3.0a1 creates evidence-backed proposals and safe macro metadata only. It does not prove endogenous language emergence or perform unrestricted automatic programming.
- Causal Capsule and Nexus Stigmergy objects in v0.3.0a1 support in-memory emission/read/adoption audit. This remains a controlled scaffold, not proof of knowledge transfer or causal learning.


## Extensibility foundation non-goals

- No automatic YAML/TOML/JSON config file loading in core.
- No UI/dashboard.
- No CLI config runner.
- No external simulation framework dependency.
- No unrestricted dynamic code execution.
- No GENESIS plugin discovery through entry points.
- No claim that custom rules, custom elements, custom schedulers, or custom topologies validate open-ended discovery.

## Deferred roadmap

- Causal Capsule / Nexus Stigmergy exchange foundations.
- QD archive hardening plus ablation/statistical protocol hooks.
- Heavier validation packs and full search-loop experiments outside the dependency-free core.


## Causal Capsule + Nexus Stigmergy Foundation

CodonTrace provides an in-memory Causal Capsule + Nexus Stigmergy foundation for controlled GENESIS-style experiments. It implements CausalCapsule lifecycle objects, CapsuleStore, NexusStigmergyLayer, ATP-gated capsule emission/read/adoption, environment-mediated capsule transfer, capsule transfer audit metrics, and typed D0/Discovery hooks for future phases.

This is not proof of knowledge transfer, not proof of causal learning, not a D0-calibrated discovery claim, not a Discovery Witness archive, not Quality-Diversity/MAP-Elites, and not open-ended discovery. Stigmergy is represented as in-memory environment-mediated signals: target organisms read from a Nexus layer/store rather than receiving direct source-to-target messages.

ADF/Dynamic Vocabulary support remains explicit and auditable: proposals use codon-width-consistent state, full-window occurrence evidence, primitive-cost-based macro cost policies, ATP_learning-gated proposal accounting, and additive extended codon-table proposals. Base GENESIS codon tables remain stable.


## D0/Discovery/QD claim limits

D0 Baseline, Discovery Witness, QD archive, ablation, and statistical protocol objects are evidence infrastructure only. They do not prove general-intelligence, artificial life, open-ended discovery, causal learning, knowledge transfer, or benchmark-rank claim. QD/MAP-Elites support is a library-level archive/evaluation/selection-pressure primitive with conservative smoke outputs. The library still does not provide a production UI, database/cloud service, automatic benchmark-rank claim, or p-value/strong-claim engine without configured evidence, controls, and ClaimGate approval.


## v0.3.0a1 Release Candidate Hardening + Scientific Evidence Pack

CodonTrace v0.3.0a1 focuses on API hardening, validation objects, compatibility snapshots, example-smoke contracts, research-validation bundle records, and claim-audit scaffolds. These are dependency-free Python object APIs only. They do not add an app, UI, dashboard, CLI, report writer, notebook generator, experiment runner, file writer, p-value engine, or external dependency. The validation pack helps researchers audit reproducibility and claim safety, but it does not prove general-intelligence, artificial life, open-ended discovery, causal-certainty claim, knowledge transfer, or benchmark-rank claim.

## v0.3.0a1 non-goal reminder

The mature-alpha hardening objects do not create an app, dashboard, CLI, experiment runner, report generator, benchmark system, p-value engine, publishing automation, or external-tool integration. They only model evidence supplied by callers.
