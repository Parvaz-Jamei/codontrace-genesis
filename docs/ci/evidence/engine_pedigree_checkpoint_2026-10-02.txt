What the new tests lock
- A birth counts as linked only when its parent id was already in an earlier census.
  A missing parent, a self-parent, or a parent that appears in the same census does not.
  No birth is not recorded as a success.
  A regained genome is still reported when the parent link fails.
- The live census parent_id matches the lineage record, including an empty parent.
- Idea4 checkpoint_fork_complete is true only as a measured restore, and that
  does not set hypothesis_supported, red_queen_proved, topology_effect_identified,
  endpoint_map_is_contact_physics, or lineage_recovery_established.
  n_unit stays "run" (one history is one replicate).
- The Idea2 side counter stays a counter, not a genotype population.
